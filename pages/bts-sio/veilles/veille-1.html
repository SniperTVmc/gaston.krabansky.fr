La cybersécurité des applications web (OWASP Top 10)

Mars 2026
Veille d'exemple : à remplacer par vos propres veilles

Dans le cadre de mes projets web (notamment le site de l'association L'Étoile du jeu), je me suis intéressé aux principales failles de sécurité recensées par l'OWASP (Open Worldwide Application Security Project), une référence dans le domaine de la sécurité applicative.

Ce que j'ai retenu

  • Les injections SQL restent l'une des failles les plus exploitées, d'où l'importance des requêtes préparées.
  • Le contrôle d'accès défaillant (broken access control) est la catégorie la plus fréquente selon le dernier classement.
  • La validation des données côté serveur est indispensable, même quand une validation existe déjà côté client.

Application concrète

J'ai mis en pratique certains de ces principes sur mes projets PHP/MySQL, notamment l'utilisation de requêtes préparées et le hachage des mots de passe avant stockage en base de données.
