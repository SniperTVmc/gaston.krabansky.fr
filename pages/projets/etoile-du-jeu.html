L'Étoile du jeu - Association

PHP HTML CSS JavaScript MySQL 2026

Site web de l'association "L'Étoile du jeu", une association de jeux de société basée à Lille. Le site a été développé en PHP, HTML, CSS et JavaScript, avec une base de données MySQL pour la gestion des membres et des événements.

Ce projet a été réalisé dans le cadre d'un projet scolaire, en collaboration avec d'autres étudiants, dont l'objectif était d'améliorer le site web existant de l'association en ajoutant de nouvelles fonctionnalités et en améliorant le design.

Section d'exemple : à relire et personnaliser

Mon rôle dans le projet

  • Développement de fonctionnalités backend en PHP (connexion à la base de données MySQL)
  • Mise en place et sécurisation d'un espace membre
  • Travail en équipe avec gestion de version via Git
