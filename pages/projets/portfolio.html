Portfolio / Site web personnel

HTML CSS JavaScript 2025 - 2026

Il s'agit du site que vous êtes en train de consulter : mon site web personnel, développé en HTML, CSS et JavaScript pur, sans framework, afin de garder un code simple et facile à faire évoluer moi-même. Ayant peu d'expérience avec le front-end, et n'étant pas un web designer qualifié, ce site a été conçu avec l'aide d'IA génératives, puis affiné et personnalisé par mes soins.

Objectifs du site

  • Présenter mon profil, mes compétences, mon parcours et mes projets à des recruteurs
  • Servir de support pour le portfolio de l'épreuve E5 du BTS SIO, option SLAM
  • Rester un site statique, simple à héberger et à faire évoluer sans base de données

Architecture technique

Le site est structuré en pages statiques HTML, avec des feuilles de style et scripts communs partagés (dossier assets/), pour garder un code aéré et compréhensible que je peux continuer à alimenter régulièrement.
